# Herramientas

Scripts propios de reconocimiento y explotación.

- [Host Discovery](host-discovery/) — barrido de hosts vivos en una subred.
- [Port Discovery](port-discovery/) — escáner de puertos con manejador de Ctrl+C.
- [WebDAV](webdav/) — comprobación y subida de ficheros vía WebDAV.
- [Process Monitor](procmon/) — monitorización de procesos del sistema.
- [Shellshock](shellshock/) — explotación de Shellshock (Python).
- [Shellshock v2](shellshock2/) — variante mejorada del anterior.
